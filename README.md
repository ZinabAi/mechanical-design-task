
# Mechanical Design Task

## Project Overview

This project is a simple 3D mechanical design created using Tinkercad.

For this task, a heart-shaped object was selected as the design. The shape was created as a 3D model with specific dimensions and then prepared for STL export.

## Design Concept

The selected shape is a simple heart. The purpose of this task is to practice creating a basic mechanical 3D model, controlling its dimensions, and exporting the final design as an STL file.

## Software Used

**Tinkercad**

## Design Specifications

| Parameter | Value |
|---|---:|
| Shape | Heart |
| Length | 50 mm |
| Width | 50 mm |
| Height | 2 mm |
| Design Type | 3D Model |
| File Format | STL |

## Modeling Process

The design was created using the following steps:

1. Selected a heart shape from the available shapes in Tinkercad.
2. Added the heart shape to the workplane.
3. Adjusted the dimensions of the shape.
4. Set the length to 50 mm.
5. Set the width to 50 mm.
6. Set the height to 2 mm.
7. Checked the final 3D model.
8. Exported the model as an STL file.

## Final Design

The final model is a flat heart-shaped 3D object with dimensions of:

**50 mm × 50 mm × 2 mm**

The 2 mm height provides the required extrusion depth for the design.
